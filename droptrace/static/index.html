Targets & advanced

Hosts on other networks, probed when a drop is suspected so the record shows several networks were dark at once — and on the baseline timer so a host your ISP blocks cannot masquerade as a witness. They also count towards the verdict, so five healthy networks cancel a false alarm.

MiB, 0 = no cap. A guard for very fast links or a data cap.

The endpoint rejects values above ~100 MB. Small requests cost a round trip each and under-report the rate.

Older probes are folded into hourly statistics (one row per target per hour, a few megabytes a year) and every failure is kept verbatim, so a drop stays provable. 0 keeps every probe for the whole retention window.

A drop is caught at the normal cadence above, then resolved at this faster one so its start and end are timed to the second.

An outage is a round where no internet target answered. Raising the round count ignores blips shorter than that many probes.

How this measures: a probe is a TCP handshake, not ICMP (raw sockets need privileges). Each round probes every target at once and writes one sample per target, tagged with a role — local (resolver, gateway), internet (public IPs) and dns. If only the internet targets fail while the local ones answer, the verdict is “ISP or upstream”; if the local ones fail too, it is “local network”. An outage row opens on the first failed round and closes when a round succeeds.
